# MVP Demo Scenario

Elysia Perp UI MVP 데모 시나리오.
Sepolia 테스트넷 기반이며 실제 자금은 사용되지 않습니다.

---

## Pre-requisite

- MetaMask 설치 및 Sepolia 테스트넷 설정
- 백엔드 API 서버 실행 (`NEXT_PUBLIC_API_URL`)
- 프론트엔드 개발 서버 실행 (`pnpm dev`)

---

## Scene 1: 지갑 연결 & 예치

**목적:** 지갑 인증과 테스트넷 자산 예치 확인

1. **Connect Wallet** 버튼 클릭
2. MetaMask 팝업에서 EIP-712 서명 승인
3. 헤더에 지갑 주소 (`0xabcd...1234` 형식) 표시 확인
4. **Deposit** 버튼 클릭
5. 토스트 알림 확인 (Deposit - Open)
6. 하단 **Assets** 탭에서 잔고 확인
   - USD: 10,000,000
   - BTC: 100
   - ETH: 1,000

**확인 포인트:**

- [ ] 지갑 연결 후 자동 로그인
- [ ] Deposit 토스트 정상 표시
- [ ] Assets 탭 잔고 반영

---

## Scene 2: Bot 활성화 & 오더북 확인

**목적:** 실시간 오더북 데이터 생성

1. 헤더의 **Bot** 토글 ON
2. 오더북에 실시간 주문이 채워지는 것을 확인
   - Binance 실시간 거래 데이터 기반
   - BTC-PERP, ETH-PERP 양쪽 모두 생성
3. 차트에서 가격 움직임 확인

**확인 포인트:**

- [ ] Bot ON 시 오더북에 주문 생성
- [ ] 차트에 캔들 데이터 반영

---

## Scene 3: 레버리지 설정 & Limit 주문

**목적:** 레버리지 조정과 지정가 주문 기능 시연

1. **BTC-PERP** 마켓 선택
2. 레버리지 버튼 (`10x`) 클릭 -> 모달에서 **20x**로 조정 -> Confirm
3. **Buy / Long** 선택
4. **Limit** 주문 타입 선택
5. 현재 Mark Price보다 **낮은 가격** 입력 (체결되지 않도록)
6. Amount 입력 (예: 0.1 BTC)
7. **Place Limit Order** 클릭
8. 토스트 알림 확인 (Limit Order - BTC - LONG - Open)
9. 하단 **Open Orders** 탭에서 주문 확인

**확인 포인트:**

- [ ] 레버리지 모달 정상 동작
- [ ] Limit 주문 토스트 (Open 상태, 사이즈, 가격)
- [ ] Open Orders 탭에 주문 표시

---

## Scene 4: Market 주문으로 포지션 진입

**목적:** 시장가 주문으로 즉시 포지션 생성

1. **Sell / Short** 선택
2. **Market** 주문 타입 선택
3. Amount 입력 (예: 0.05 BTC)
4. **Place Market Order** 클릭
5. 토스트 알림 확인 (Market Order - BTC - SHORT - Open)
6. 하단 **Positions** 탭에서 포지션 확인
   - Market, Size, Entry Price
   - Liq. Price (청산가)
   - Unrealized PnL (실시간 변동)

**확인 포인트:**

- [ ] Market 주문 즉시 체결
- [ ] Positions 탭에 포지션 표시
- [ ] PnL 실시간 업데이트

---

## Scene 5: 주문 취소

**목적:** 개별 취소 및 전체 취소 기능 시연

### 5-A: 개별 취소

1. **Open Orders** 탭 이동
2. Scene 3에서 넣은 Limit 주문의 **X** 버튼 클릭
3. 토스트 알림 확인 (Limit Order - BTC - LONG - Cancelled)

### 5-B: 전체 취소 (선택)

1. Limit 주문 여러 개 추가 생성
2. **Cancel All** 버튼 클릭
3. 모든 주문 일괄 취소 확인

**확인 포인트:**

- [ ] 개별 취소 토스트 (Cancelled 상태)
- [ ] Cancel All 시 모든 주문 제거
- [ ] 취소 후 잔고(마진) 복구 확인

---

## Scene 6: 포지션 부분 종료 & 전체 종료

**목적:** 포지션 관리 기능 시연

### 6-A: 부분 종료 (50%)

1. **Positions** 탭 이동
2. Short 포지션 행의 **X** 버튼 클릭 -> ClosePositionModal 열림
3. 슬라이더를 **50%** 로 조정
4. 예상 PnL 확인 (녹색: 이익, 빨간색: 손실)
5. **Close Position** 클릭
6. Positions 탭에서 사이즈가 줄어든 것 확인

### 6-B: 전체 종료 (100%)

1. 남은 포지션의 **X** 클릭
2. 슬라이더 **100%** -> **Close Position**
3. Positions 탭에서 포지션 완전 종료 확인

**확인 포인트:**

- [ ] 부분 종료 시 잔여 사이즈 정확
- [ ] PnL 계산 표시
- [ ] 전체 종료 후 포지션 제거

---

## Scene 7: 청산 시연

**목적:** 고레버리지 포지션의 청산가 확인

> 청산은 서버사이드에서 처리됩니다.
> 가격이 Liq. Price에 도달하면 자동 청산되지만, 타이밍을 보장할 수 없으므로
> 데모에서는 청산가를 보여주며 설명하는 방식을 권장합니다.

1. 레버리지를 **최대** (예: 50x)로 설정
2. **Market** 주문으로 포지션 진입 (큰 사이즈)
3. Positions 탭에서 **Liq. Price**가 현재가에 가까운 것 확인
4. "이 가격에 도달하면 포지션이 자동 청산됩니다" 설명
5. (운이 좋으면) 가격 변동으로 실제 청산 발생

**확인 포인트:**

- [ ] 고레버리지 시 Liq. Price가 현재가 근처
- [ ] 청산가 표시 정확

---

## Scene 8: 마켓 전환

**목적:** 멀티 마켓 지원 시연

1. 마켓 셀렉터에서 **ETH-PERP** 선택
2. 차트, 오더북, Mark Price가 ETH로 전환되는 것 확인
3. ETH-PERP에서 주문 1건 생성
4. 다시 **BTC-PERP**로 전환하여 기존 데이터 유지 확인

**확인 포인트:**

- [ ] 마켓 전환 시 차트/오더북 즉시 반영
- [ ] 마켓별 독립적인 주문/포지션
